# TracerSET

Requires Python3.10 or better.
```
Usage:
       python3 tracerset.py beginner <file.py>
       python3 tracerset.py intermediate <file.py>
       python3 tracerset.py advanced <file.py>
```
Preliminary testing has been done on {Unix/Linux, Windows} Operating Systems. Present dependencies are as follows:
```
libcst==1.8.6
pytest==8.4.1
```
